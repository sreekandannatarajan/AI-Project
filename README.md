**Prerequisites**
Please ensure the following software is installed before getting started:
Python 3.13.12
pip (Python package manager)

**Environment Setup**
To configure the environment, you can follow either of these methods:
Refer to the requirements.txt file and install the required packages individually.
Install all dependencies at once by running the following command in the command line:
pip install -r requirements.txt

**Running the Project**
You can use either the .ipynb file or the .py file:
Use JupyterLab to open and run the .ipynb file.
If you prefer a Python script, you can run the .py file directly.
